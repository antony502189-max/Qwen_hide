# Контроллер текущего ChatGPT

Версия перенесена с Classic на приложение из пакета OpenAI.Codex. Требуются Windows x64 и установленный текущий ChatGPT. Сборка и установка: [README](README.md#build-and-install).

## Включение и выключение

Сборка создаёт dist-single\ChatGPTDesktopController.exe. В установленной папке `%LOCALAPPDATA%\ChatGPTCurrentController\app\<версия>` файл должен называться `ChatGPTController.exe`.

Создайте два ярлыка на установленный файл:

- **ChatGPT — Включить контроллер**: без аргументов.
- **ChatGPT — Выключить контроллер**: аргумент `--stop`.

Выключение использует штатный обработчик восстановления окна, без принудительного завершения. Код завершения 2 означает, что завершение не подтвердилось. Команда работает для полной версии в указанной установленной папке; при уже выключенном контроллере ничего не делает.

**Ctrl+Alt+Esc** восстанавливает окно и завершает контроллер. **Ctrl+Alt+Q** только прячет/показывает ChatGPT, оставляя контроллер включённым. **Ctrl+Alt+D** открывает диагностику.

По умолчанию окно контроллера и его значок в трее не показываются. Во время работы скрывается кнопка ChatGPT с панели задач и выполняется попытка скрыть его нативный значок. При штатном выходе выполняется восстановление.

## Клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+Q | Скрыть/показать ChatGPT |
| Ctrl+Alt+X | Сквозные клики |
| Ctrl+Alt+T | Поверх остальных окон |
| Ctrl+Alt+↑ / ↓ | Прозрачность |
| F6 | Снимок монитора в буфер |
| Ctrl+Alt+V | Показать и защитить окно, вставить изображение |
| Ctrl+Alt+D | Диагностика |
| Ctrl+Shift+R | Прежнее управление доступной кнопкой голоса |
| Ctrl+Alt+Esc | Восстановление и выход |

Right Ctrl для аудиомикса требует настройки виртуального аудиоустройства.

## Диктовка без контроллера

Добавьте объект в массив `%USERPROFILE%\.codex\keybindings.json`, сохранив остальные привязки, и полностью перезапустите ChatGPT:

```json
{ "command": "globalDictationSingleTap", "key": "Ctrl+Shift+D" }
```

Это команда самого приложения, контроллер её не перехватывает. Работа после перезапуска подтверждена пользователем на проверенной версии.

## Границы проверки

Основное окно исключалось из проверенных захватов PrintWindow, GDI и Windows Graphics Capture. Последняя проверка DXGI была неубедительной из-за однотонного контрольного изображения. Конкретная программа демонстрации экрана не проверялась.

Скрытое окно 720x180, соответствующее по признакам всплывающей диктовке, отклонило установку защиты. **Скрытие всплывающего окна диктовки не подтверждено.** Ответ Windows на скрытие нативного значка в трее не заменяет визуальную проверку.

Настройки, журналы и восстановление: `%LOCALAPPDATA%\ChatGPTCurrentController`. Данные Classic отделены. Подробности: [проверки переноса](CURRENT_PORT_VERIFICATION.md).
