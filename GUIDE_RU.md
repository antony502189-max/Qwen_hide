# Контроллер ChatGPT Classic — руководство

1. Откройте обычное установленное приложение ChatGPT Classic.
2. Запустите `ChatGPTDesktopController.exe`.
3. Нажмите `Attach / refresh`, если приложение было открыто позже контроллера.

Значок в области уведомлений позволяет показать контроллер, открыть диагностику или безопасно завершить работу. В настройках доступны запуск в области уведомлений и необязательный запуск проверенного ChatGPT Classic, если приложение не запущено. Повторное подключение выполняется раз в пять секунд и каждый раз проверяет путь к файлу.

Горячие клавиши: `Ctrl+Alt+Q` скрыть/показать; `Ctrl+Alt+X` сквозные клики; `Ctrl+Alt+T` поверх окон; `Ctrl+Alt+Up/Down` прозрачность (35–100%); `F6` снимок активного рабочего окна в буфер обмена Windows; `Ctrl+Alt+V` показать ChatGPT, сфокусировать доступный редактор и вставить изображение; `Ctrl+Alt+D` диагностика; `Ctrl+Alt+Esc` аварийное восстановление и выход.

Вставка намеренно завершается диагностической ошибкой, если редактор не найден через UI Automation. Координатных кликов нет. Нативное сочетание голоса не было обнаружено, поэтому `Ctrl+Shift+R` вызывает реальную доступную кнопку голоса через UI Automation `InvokePattern`, без координат. Опциональный микс по Right Ctrl запускается только после выбора физического микрофона, источника loopback и распознанного не-default виртуального выхода. Настройки Windows и микрофон Zoom/Teams никогда не меняются; на этой машине виртуального выхода пока нет, поэтому запуск будет безопасно отклонён.

Журнал восстановления создаётся только перед первым изменением окна. При обычном/аварийном выходе и после сбоя при следующем запуске восстанавливаются исходные стили, видимость, TopMost, прозрачность и положение окна.
